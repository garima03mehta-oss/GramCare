# GramCare 🏥

## Overview
GramCare is a smart healthcare inventory management system for rural health centers. It helps manage medicine inventory, detect low stock, and redistribute medicines between nearby centers.

## Features
- Secure Login & Registration
- Medicine Inventory Management
- Global Medicine Search
- Low Stock Detection
- Smart Redistribution Suggestion
- Medicine Request & Approval
- Delivery Tracking
- Dashboard with Stock Chart

## Tech Stack
- React.js
- Vite
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- Chart.js
- Vercel
